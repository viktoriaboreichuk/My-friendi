# Lunari 0.2.7 — ТЗ следующего обновления

**Статус:** утверждено к реализации  
**Экран:** Главная  
**Принцип:** прикреплённые и утверждённые графические ассеты являются источником истины; не перерисовывать их кодом и не заменять «похожими» вариантами.

## UI-11 — Утверждённый логотип

Использовать утверждённый графический логотип Lunari как единый готовый ассет.

Требования:
- только надпись `LUNARI` в утверждённом серебристо-лавандовом кристальном оформлении;
- большой месяц над буквой `L` отсутствует;
- дополнительное наружное свечение букв и элементов отсутствует;
- под словом расположен маленький полумесяц;
- слева и справа от маленького полумесяца находятся две тонкие горизонтальные линии;
- не собирать логотип системным шрифтом, отдельными символами, звёздами или Canvas;
- не менять форму букв, пропорции, цвет и декоративный элемент внутри `A`.

Ресурс приложения: `lunari_logo_027`.

## UI-12 — Шесть оформлений карточек

Для каждой из шести карточек использовать отдельный утверждённый прозрачный графический overlay. Один файл = одна карточка.

Соответствие:
1. `Персонажи` → overlay 01;
2. `Миры` → overlay 02;
3. `Чаты` → overlay 03;
4. `Память` → overlay 04;
5. `Профили` → overlay 05;
6. `Снимки` → overlay 06.

Требования:
- прямоугольная серебристо-лавандовая рамка, её блики и декоративная вязь берутся непосредственно из соответствующего overlay;
- правый узор у каждой карточки отличается — никаких повторов одного Canvas-узора;
- тонкое золотистое кольцо вокруг круглой иллюстрации берётся из overlay;
- старую программно рисуемую рамку корпуса и `LunariCardOrnament026` убрать;
- старую фиолетовую рамку вокруг круглой картинки поверх золотого кольца не накладывать;
- сами шесть круглых иллюстраций категорий сохранить без изменения содержания;
- сохранить утверждённую ранее прозрачность стеклянного корпуса карточки: фон должен хорошо просвечивать;
- сохранить названия, подзаголовки, порядок карточек, стрелки и маршруты.

Ресурсы приложения: `lunari_card_overlay_01` … `lunari_card_overlay_06`.

## UI-13 — Новый фон главного экрана

Использовать прикреплённый утверждённый фон с:
- большим полумесяцем в верхней левой части;
- звёздным небом и фиолетовой галактической полосой;
- облаками по краям;
- долиной и горами;
- замком в нижней правой части.

Требования:
- фон занимает весь главный экран;
- `ContentScale.Crop`, привязка сверху по центру;
- не накладывать поверх фона полноэкранное затемнение;
- замок, облака, звёзды и лунный свет должны быть видны сквозь прозрачные карточки.

Ресурс приложения: `lunari_home_bg_027`.

## UI-14 — Прокрутка карточек под фиксированным логотипом

Шапка с логотипом остаётся фиксированной. Прокручивается только список карточек.

Поведение:
- первая карточка в исходном состоянии располагается ниже шапки;
- при прокрутке карточки уходят вверх;
- верхняя граница области списка находится под зоной логотипа;
- карточка, дошедшая до этой границы, обрезается и исчезает, а не рисуется поверх логотипа;
- выше границы шапки содержимое списка не отображается;
- нижняя навигация остаётся фиксированной;
- все 6 карточек доступны прокруткой.

## Не менять

- package/applicationId: `com.vega.yakor`;
- пользовательские данные и совместимость обновления поверх установленной Lunari;
- содержание круглых иллюстраций категорий;
- тексты карточек и маршруты;
- поведение нижней навигации, кроме необходимых технических адаптаций под область прокрутки.

## Сборка и выдача APK

1. Сборка выполняется в рабочей ветке и CI.
2. Красная/частично упавшая сборка пользователю **не показывается и не предлагается**.
3. Исправления продолжаются до полностью зелёного GitHub Actions run.
4. Только из зелёного run брать unsigned APK.
5. Подписывать постоянным ключом Lunari через Android `apksigner` (не `jarsigner`).
6. Обязательно проверить APK Signature Scheme v2/v3, package `com.vega.yakor`, версию и совпадение сертификата с предыдущей рабочей Lunari.
7. Только после всех проверок выдавать APK для установки поверх текущего приложения.
