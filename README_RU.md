# Якорь 0.1 — персональный ролевой чат для Android

Первая рабочая версия собственного приложения в духе Friendi, но с разделёнными слоями личности, канона, памяти и отношений.

## Что уже есть

- несколько персонажей;
- аватар и галерея референсов персонажа;
- длинные поля внешности, характера, биографии, речи, правил и запретов без искусственного лимита в несколько сотен/тысяч знаков;
- несколько пользовательских образов со своими фото и галереями;
- отдельные миры/каноны;
- несколько чатов;
- структурированная память;
- отдельное состояние отношений и незакрытых сюжетных линий;
- автоматический подбор релевантных воспоминаний и кусков большого канона;
- антидрейф: второй запрос проверяет, не распался ли характер в ответе;
- автопамять: после обмена репликами отдельный запрос извлекает важные факты/события и обновляет отношения;
- ручное редактирование и удаление памяти;
- снимки состояния и откат;
- экспорт/импорт резервной копии JSON;
- API-ключ вводится после установки и шифруется Android Keystore;
- поддержка OpenAI Responses API и OpenAI-compatible Chat Completions API.

## Важно про «без лимита знаков»

В базе приложения длинные описания и канон хранятся полностью. Но у любой LLM конечное окно контекста. Поэтому приложение не обязано каждый раз отправлять весь огромный канон: оно выбирает релевантные фрагменты. Размер служебного контекста можно менять в настройках.

## Как получить APK через GitHub Actions

1. Создайте аккаунт GitHub, если его нет.
2. На GitHub нажмите **New repository** и создайте пустой репозиторий, например `yakor`.
3. Распакуйте архив проекта на компьютере или телефоне.
4. Загрузите **содержимое** папки `yakor_android` в корень репозитория. В корне должны быть `app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`.
5. Откройте вкладку **Actions** в репозитории.
6. Выберите workflow **Build Yakor APK**.
7. Нажмите **Run workflow** → **Run workflow**.
8. После завершения откройте выполненный запуск. Внизу страницы появится раздел **Artifacts**.
9. Скачайте `yakor-debug-apk`. Внутри будет `app-debug.apk`.
10. Перенесите APK на Android-телефон и откройте его. Android может попросить разрешить установку приложений из этого источника.

При обычном `push` в ветку `main`/`master` сборка также запускается автоматически.

## Первый запуск

1. Откройте **Мои профили** и заполните свой образ.
2. Откройте **Персонажи** → **Создать персонажа**. Добавьте фото, внешность, характер, биографию, речь и правила.
3. При необходимости создайте **Мир / канон** и прикрепите его к персонажу.
4. Откройте **Настройки ИИ**.
5. Для OpenAI оставьте режим **OpenAI Responses API**, endpoint `https://api.openai.com/v1/responses`, укажите доступную вашему API модель и свой API-ключ.
6. Создайте **Новый чат**, выбрав персонажа и свой профиль.

## Расход API

- обычный режим: 1 запрос на реплику;
- антидрейф: +1 запрос;
- автопамять: +1 запрос.

Антидрейф и автопамять отключаются независимо.

## Безопасность ключа

Ключ не зашит в исходный код или APK и не попадает в экспорт резервной копии. После ввода он шифруется ключом из Android Keystore. Но это всё равно мобильный клиент: для публичного распространения приложения правильнее вынести API-вызовы на собственный сервер-прокси и не раздавать один общий секретный ключ пользователям.
