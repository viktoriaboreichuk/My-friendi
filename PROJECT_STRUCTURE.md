# Архитектура Якоря 0.1

## Слои

1. CharacterCard — устойчивое ядро персонажа. Автопамять его не редактирует.
2. UserProfile — образ пользователя для конкретной истории.
3. WorldCard — полный канон мира; релевантные фрагменты выбираются перед запросом.
4. MemoryEntry — долговременные факты, эпизоды, обещания, секреты и незакрытые линии.
5. RelationshipState — изменяемые отношения, текущее настроение, незакрытые линии, приватные заметки персонажа.
6. ChatThread / Message — отдельная история конкретного чата.
7. Snapshot — точка отката данных.
8. AiClient — вызов LLM, антидрейф и автопамять.
9. ContextEngine — подбор релевантного канона и воспоминаний.

## Принцип антираспада

Ядро персонажа каждый раз заново включается в developer/system-инструкции. Временные отношения и настроение находятся в отдельном слое и не могут автоматически переписать исходный CharacterCard.

## Ограничения 0.1

- релевантность памяти/канона пока определяется локальным лексическим совпадением, без embeddings;
- изображения используются как визуальные референсы интерфейса, но пока не отправляются модели как vision-вход;
- нет голосового режима;
- нет групповых чатов с несколькими персонажами;
- debug APK подписывается стандартным debug-ключом GitHub runner; для публикации нужен release signing.
